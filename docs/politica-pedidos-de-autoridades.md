# Política: pedidos de autoridades públicas sobre dados

Adotada pelo cliente em 09/out/2026, na verificação do app RecepClinic na Meta (Tratamento de dados).
**A revisar pelo advogado junto com as páginas legais, antes do 1º piloto.**

Vale para qualquer pedido de autoridade pública (judicial, policial, administrativa, de outro país)
sobre dados de pacientes, clínicas ou usuários guardados pelo RecepClinic, inclusive os recebidos
da Meta (WhatsApp).

1. **Análise da legitimidade.** Nenhum dado é entregue antes de conferir se o pedido é válido: quem
   pede, a base legal (ordem judicial ou requisição prevista em lei) e se a autoridade é
   competente. Na dúvida, consultar o advogado antes de responder.
2. **Contestação.** Pedido sem base legal, genérico demais ou de autoridade sem competência é
   recusado ou contestado pelos meios legais, com o advogado.
3. **Minimização.** Só se entrega o que o pedido exige: os dados, o período e a clínica indicados,
   nada além. Quando a lei permitir, a clínica dona dos dados é avisada.
4. **Registro.** Cada pedido fica registrado: data, autoridade, o que foi pedido, a resposta dada, a
   base legal, o raciocínio e quem cuidou. O registro é guardado por pelo menos 5 anos.

Responsável: o titular do RecepClinic (até haver um encarregado de dados definido).
